# 创业四刀 · 内容资产包

> 来源：2026-07-23 由"创业领域最重要的问题是什么"讨论延伸而来。
> 核心命题：创业最重要的问题不是"做什么能赚钱"，而是
> **"去掉这轮红利、去掉这层关系、去掉这次运气，你还能不能赚到钱？"**
> 即**能力归因**。大多数失败=把红利当能力，用杠杆放大一个未经验证的幻觉。

---

## 四刀框架（底层逻辑）

| 刀 | 切什么 | 关键判断 |
|----|--------|---------|
| 第一刀｜需求验证 | 真伪 | 有没有陌生人真掏钱 |
| 第二刀｜能力归因 | 运气 vs 能力 ⭐最狠 | 红利退潮后还能不能赚 |
| 第三刀｜现金流与杠杆 | 生死时刻 | 不赚钱能活几个月 |
| 第四刀｜创始人天花板 | 未来/升华 | 每周留几小时学习 |

四刀同源，输出三种形态（见下），是老杨 IP 内容矩阵的骨架。

## 资产一｜「100位普通人」通用采访提纲（四刀模板）

每个采访对象都切这四刀。前两刀决定素材深度，第三刀决定情绪浓度（核弹素材），第四刀决定升华方向。

**第一刀｜需求验证**
- "你现在做的事，第一个掏钱的人是谁？陌生人，还是熟人？"
- "有没有人当面拒绝过你？他原话怎么说的？"
- 追问：连续问三次"那人为什么愿意付钱"，挖到底层需求

**第二刀｜能力归因 ⭐（最能分人的成色）**
- "你做成的那部分，哪些是赶上了好时候/好平台/好关系，哪些是你自己的本事？"
- "如果重来一次，去掉那个资源，你还能成吗？"
- 诚实的人会主动认运气，虚荣的人全归自己——一眼分出谁值得拍

**第三刀｜现金流与杠杆**
- "你最缺钱、最危险的一次，是什么时候？那天银行卡里有多少？" → 套核弹数字（001号老张的100万→负债300万即此刀挖出）
- "怎么扛过来的？借了谁的钱？" → 套支撑系统/温情线

**第四刀｜天花板**
- "你每周，专门留多少时间给自己学习？"
- "你最近一次改变一个重要看法，是什么时候？" → 分辨是否固步自封

> 用法：专业背景强的（工程师/医生/高管）重点切第二刀；中年转型的重点切第三、四刀。

## 资产二｜口播短视频脚本：「为什么越专业的人，创业越容易死？」

时长60-70秒 | 老杨对镜头口播 | 抖音/视频号/小红书通用 | 为"商业系统教练"定位立旗

```
【Hook 0-3秒】反常识
  "你发现没——越专业的人，出来创业，死得越快？
   风电工程师、大厂高管、医生、律师……越厉害，摔得越狠。"

【阐释 3-22秒】破题
  "因为他们犯了同一个错——
   把平台的能力，当成了自己的能力；
   把时代的红利，当成了自己的本事。
   电梯在往上走，他以为是自己腿在爬。"

【例子 22-42秒】用老杨自己的故事（最强信任）
  "我自己就栽过这个跟头。
   曾经负债300万——不是因为不努力，
   是我错把一段红利期赚的钱，当成了自己的本事。
   红利一退，杠杆一加，当场裸泳。"

【解法 42-58秒】落定位
  "后来我想明白一件事：
   能让你穿越周期的，不是能力，是系统——
   一个不靠运气、不靠关系、不靠某个人，也能持续赚钱的系统。
   这，就是我现在教普通人做的事。"

【CTA 58-65秒】导流到自检清单
  "想转型的，先别急着 All in。
   评论区扣1，我发你一份「创业自检清单」——
   四个问题，答不上来，就先别开始。"
```

拍摄要点：全程一人对镜头，可坐可走动；"例子"段沉下来（真实经历自带 sincerity）。

### 普通人创业自检清单
#### 开始之前，先回答这 4 个问题

**Q1｜你的东西，有陌生人付过钱吗？**
- 🔴 红线：只有亲戚朋友捧场，没有一个陌生人掏过钱
- 老杨：熟人的夸是感情，陌生人的钱才是市场。

**Q2｜你赚到的钱，去掉平台/关系/红利，还剩多少？**
- 🔴 红线：离开现在的公司、人脉、这波风口，你立刻就不会赚了
- 老杨：电梯停了，你还能不能自己爬楼？

**Q3｜一分钱不赚，你能活几个月？**
- 🔴 红线：少于6个月，或靠借贷维持 → 没有犯错空间
- 老杨：创业的第一道数学题，不是能赚多少，是能亏多久。

**Q4｜你每周，专门留给学习的时间有几小时？**
- 🔴 红线：0。还在靠3年前的经验吃饭
- 老杨：业务的天花板，就是你停止学习的那一天。
