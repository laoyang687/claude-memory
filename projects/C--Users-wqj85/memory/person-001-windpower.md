## 备选切入角度：行业反差（2026-07-23 补录）

> 定位：原 24/25 反差英雄线 Hook **不动**。此为**备选开场 + 深挖采访问题**，
> 用"新能源越便宜越难赚钱"的行业反常识勾好奇，再落到人。
> 由小可基于"新能源发电最重要的问题"讨论延伸而来。

### 备选Hook（2版，均为原Hook的补充，非替换）

**版本A｜行业反差压一句（推荐）**
- 画面：风电场大全景 → 切他深夜电脑前背影
- 旁白："风车越转越便宜，他的日子却越来越难。管过上亿风电项目的人，创业失败，负债300万。如今凌晨，还在学AI。"
- 卖点：第一句把行业反差+人物命运压成一句话。

**版本B｜质疑常识开场（适合做"100位普通人"系列总Hook）**
- 画面：风电场空镜 → 他正脸特写
- 字幕+旁白："新能源，国家扶持，朝阳产业——真这么赚钱吗？"
- 人物原声切入："设备是越来越便宜，可这行……反而越来越难做了。"
- 旁白接："他管过上亿的风电项目。如今创业失败，负债300万。"
- 前提：采访第1题得挖到一句干脆的原声。

### 深挖采访提纲（8问，层层套故事）

**行业真相层（套"反常识"，让内行人开口）**
1. 外行觉着新能源躺着赚钱。你最想跟外行说的"真话"是哪句？ → 套行业总判断/金句
2. 设备越便宜反而越难，难在哪？给个亲历的例子。 → 核心反差，逼具体故事（重点题）
3. 管过的上亿项目，赚的和亏的差别到底在哪？ → 引出"系统/制度/风险"，为创业栽跟头埋伏笔

**个人反差层（落到人，接原脚本）**
4. 最风光时银行卡大概多少钱？过什么日子？ → 套巅峰数字与画面（车/饭局/张总）
5. 决定自己干那一刻，是真觉得能成还是憋着一口气？ → 挖不甘心，不只是善良动机

**谷底+不屈层（给原声灌情绪）**
6. 看到负债300万那一刻第一个念头？想放弃过吗？ → 给原声③加"那一刻"（重点题）
7. 攥着那个地瓜当第一笔收入，心里什么滋味？ → 给原声⑥加厚度（重点题）

**升华层（套结尾金句）**
8. 拿风电场里一样东西形容现在的自己——风车、荒野、风，还是别的？ → 逼比喻金句，可做结尾/海报

> 使用：第 2、6、7 题多聊几遍取最自然的；第 8 题放最后，人放松了才说得好。

## 已挖掘素材（前采记录）

### 创业初衷
"还是想要做点事儿，带动身边的亲戚朋友赚些钱。尤其是我是出生在东北的农村小山村，看着身边的乡亲们还是停留在几十年前的生活状态，大家过得也都比较拮据、比较艰苦，所以我是想做点事儿，能带动身边的亲戚朋友致富。"

**分析**：动机不是贪心，是善良 → 让失败变得悲壮而非可悲 → 观众产生同情+敬佩

### 怎么失败的
"盲目地上杠杆，利用了银行贷款，然后又套了信用卡，盲目地进行投资。结果投资失败，还是因为对于风险没有控制意识，导致损失惨重。"

**分析**：毫不甩锅的诚实 → 信任感极强

### 最绝望的时刻 🔥
"最绝望的那天，发现自己银行卡里边从原来的将近100万的存款变成了负债300万。"

**分析**：核弹级素材。数字具体（100万→负债300万=400万的落差），每个人都能想象那个打开手机银行的瞬间。不需要煽情，事实本身有摧毁力。

### 镜像共振（与老杨的人生对照）
- 他：东北农村小山村 → 你：东北小山村
- 他：负债300万 → 你：曾经负债300万翻身成功
- 他：两个孩子父亲 → 你：两个孩子父亲
- 他是**翻过来之前的老杨**，老杨是**翻过来之后的他**

### 老婆那句话 💣💣💣
"没事儿，一起还，慢慢还。"
还引用了妈妈的话："还得拼。"

**分析**：7个字比任何旁白都管用。"一起还"说明没走，"慢慢还"说明不急，"还得拼"是两代人的力量叠加。全片最催泪的瞬间。

### AI学习成果（具体细节）
- 工具：ChatGPT、Claude Code
- 同声翻译软件：说话实时翻译成英语
- 视频制作：苏轼《定风波》30集视频
- 门店设计：帮蜜薯哥做设计 → 得到一个地瓜（第一笔"收入"）💣💣💣
- 门店设计：帮徐州包子铺老板做设计 → 150元（第一笔现金收入）
- 文稿电子书：AI写文稿做PDF电子书 → 卖了2份，9.9元

**分析**："管上亿项目 → 第一个地瓜"这个反差是全片最强笑点+泪点。

### 孩子的话 💣💣
- 儿子看到他用AI帮蜜薯哥卖红薯，说："这才是AI才有的价值啊！"
- 女儿和儿子对低谷中没有屈服的父亲表示支持
- **"孩子们认为父亲是全天下最厉害的男人"**

**分析**：不是因为成功而厉害，是因为没倒下而厉害。这是全片的灵魂升华。
