# 「100位普通人」采访视频制作 SOP

> 栏目定位：**《普通人的重启》**
> 副标题：记录100个普通人在AI时代重新开始的故事
> 基于「一条」创始人徐沪生方法论逆向拆解
> 更新日期：2026-06-10

---

## 一、栏目核心定位

```
我们不是单纯采访，而是在做三件事：

1. 帮普通人整理人生故事
2. 帮普通人提炼个人品牌
3. 帮普通人找到AI时代的新机会

核心公式：
一条的公式：小众高品质生活 × 杂志审美 = 让小众被看见
我们的公式：普通人的真实故事 × 情感共鸣 = 每个人都值得被看见
```

**商业闭环**：

```
采访普通人 → 挖出人生故事 → 提炼人物定位 → 做成短视频
→ 帮他建立个人品牌 → 产生咨询/陪跑/品牌服务变现
```

**与老杨个人定位的关系**：AI时代个人商业系统教练——你不是只拍他们，你是在帮他们完成一次"人生品牌重塑"。

## 二、选题标准（四维筛选法）

| 维度 | 筛选问题 | 权重 |
|------|---------|------|
| **反差** | 这个人有没有"不普通"的一面？ | ⭐⭐⭐ |
| **共鸣** | 观众能不能在他身上看到自己？ | ⭐⭐⭐ |
| **画面** | 他的生活/工作场景能拍出感觉吗？ | ⭐⭐ |
| **分享** | 看完会不会想转给某个朋友？ | ⭐⭐ |

**规则**：四维总评分 ≥ 8颗星 → 值得拍；≥ 10颗星 → 必须拍

**选题来源**：
- 身边的人（同事、邻居、朋友的朋友）
- 社交媒体上的普通人故事
- 日常生活偶遇的有意思的人

## 三、五段式故事结构（采访SOP核心）

> 每一段对应视频的一个结构模块，段段有功能，不能少

### 第一段：他是谁？（建立真实感）

**目标**：先让观众认识这个人。不要太煽情，重点是真实。

| # | 问题 | 用途 |
|---|------|------|
| 1 | 你叫什么？今年多大？现在主要在做什么？ | 基础信息 |
| 2 | 你以前觉得自己是一个什么样的人？ | 自我认知 |
| 3 | 别人眼里的你，和真实的你一样吗？ | 制造反差伏笔 |

### 第二段：他经历过什么？（命运转折）

**目标**：进入命运转折，把"普通人"变成"有命运感的人"。

| # | 问题 | 用途 | 核心度 |
|---|------|------|--------|
| 4 | 你人生最难的一段时间是什么时候？ | 定位低谷 | ⭐⭐⭐ |
| 5 | **那天具体发生了什么？** | 情绪爆点 ★ | ⭐⭐⭐ |
| 6 | 你当时最害怕的是什么？ | 挖恐惧 | ⭐⭐ |
| 7 | 有没有一个瞬间，让你觉得自己快撑不住了？ | 崩溃时刻 | ⭐⭐⭐ |
| 8 | 那时候你最不敢面对谁？ | 关系张力 | ⭐⭐ |

> ★ **"最绝望的那天发生了什么"是全片情绪爆点。普通人的故事，如果没有"低谷"，观众很难共情。**

### 第三段：他为什么没有放弃？（情感高潮）

**目标**：挖家庭、爱人、孩子、父母。**这是短视频最容易传播的段落。**

| # | 问题 | 用途 | 核心度 |
|---|------|------|--------|
| 9 | 那段时间，谁一直在你身边？ | 支撑系统 | ⭐⭐⭐ |
| 10 | **你老婆/家人有没有说过一句让你一直记到现在的话？** | 金句 ★★★ | ⭐⭐⭐ |
| 11 | 你有没有瞒着家里人一些压力？ | 隐藏张力 | ⭐⭐ |
| 12 | **孩子知道你那时候有多难吗？** | 隐藏泪点 ★★ | ⭐⭐⭐ |
| 13 | 你最想对家人说什么？ | 情感出口 | ⭐⭐ |

> ★ **"老婆说过什么让他感动的话"——真正打动人的往往不是商业成功，而是家人没有放弃他。**
> ★★ **"孩子知不知道爸爸在做什么"——隐藏泪点。中年男人最动人的地方：一边崩溃，一边还想在孩子面前撑住。**

### 第四段：他现在怎么重新开始？（行动转折）

**目标**：从情绪转向行动。**决定这个故事不是卖惨，而是"普通人的自我重启"。**

| # | 问题 | 用途 | 核心度 |
|---|------|------|--------|
| 14 | 你现在最想改变的是什么？ | 当下动力 | ⭐⭐ |
| 15 | 你为什么开始学习AI？ | 转型契机 | ⭐⭐⭐ |
| 16 | **你现在具体在学什么？学到什么程度？** | 具体行动 ★ | ⭐⭐⭐ |
| 17 | 你每天大概花多少时间？ | 付出程度 | ⭐⭐ |
| 18 | 你有没有一个小目标？比如三个月后想做到什么？ | 短期愿景 | ⭐⭐ |

> ★ **"具体在学什么AI"把故事从"苦情"拉回到"希望"。观众看到：这个人不是在抱怨，而是在自救。**

### 第五段：他想成为谁？（品牌提炼）

**目标**：提炼人物品牌，产出片尾金句。

| # | 问题 | 用途 | 核心度 |
|---|------|------|--------|
| 19 | 如果用一句话介绍现在的你，你会怎么说？ | 人物标题 | ⭐⭐⭐ |
| 20 | 你希望别人记住你哪一点？ | 个人标签 | ⭐⭐ |
| 21 | 如果未来有人遇到和你一样的困境，你想对他说什么？ | 升华金句 | ⭐⭐⭐ |
| 22 | 一年后的你，最希望自己变成什么样？ | 未来画面 | ⭐⭐ |
| 23 | 你希望孩子以后怎么看今天的你？ | 情感升华 | ⭐⭐⭐ |

---

### 3个必问金句问题（穿插使用）

这三个问题非常容易出金句，可以在任意段落合适时抛出：

| # | 问题 | 效果 | 建议使用时机 |
|---|------|------|-------------|
| X1 | **你最想回到哪一天，抱抱那时候的自己？** | 容易让人破防 | 第二段（经历）或第三段（家人） |
| X2 | **如果把你前半生写成一句话，会是什么？** | 适合提炼人物标题 | 第五段（品牌） |
| X3 | **你现在最想靠AI改变哪件事？** | 把栏目和AI时代连接 | 第四段（重启） |

## 四、视频结构模板

### 标准时长：3-5分钟

```
┌─────────────────────────────────────────────────┐
│  HOOK 开头钩子（0-15秒）                          │
│  ├── 前3秒：强冲击画面 + 一句悬念旁白              │
│  └── 3-15秒：交代人物身份 + 核心反差              │
├─────────────────────────────────────────────────┤
│  第一段：他是谁（15秒-45秒）                      │
│  旁白交代身份 → 快速建立人物 → 反差伏笔           │
├─────────────────────────────────────────────────┤
│  第二段：他经历了什么（45秒-1分30秒）★ 情绪爆点    │
│  命运转折 → 人物原声 → 谷底时刻                   │
├─────────────────────────────────────────────────┤
│  第三段：他为什么没放弃（1分30秒-2分15秒）★ 催泪段  │
│  家人金句 → 孩子视角 → 情感高潮                   │
├─────────────────────────────────────────────────┤
│  第四段：他怎么重启的（2分15秒-2分45秒）           │
│  学AI → 具体行动 → 希望画面                      │
├─────────────────────────────────────────────────┤
│  第五段：他想成为谁（最后30秒）★ 升华金句          │
│  人物金句 → 音乐高潮 → 空镜停留3-5秒              │
└─────────────────────────────────────────────────┘
```

### 旁白硬指标

| 指标 | 数值 |
|------|------|
| 3分钟视频旁白 | 不超过600字 |
| 5分钟视频旁白 | 不超过950字 |
| 必须覆盖 | 8-10个信息点 |
| 结尾 | 必须升华 |
| 素材比 | 多拍多删，精华留下 |

### 叙事结构（五幕式）

1. **Who（他是谁）** → 建立真实感
2. **What happened（他经历了什么）** → 命运转折
3. **Why not give up（他为什么没放弃）** → 情感高潮
4. **How to restart（他怎么重启）** → 行动转折
5. **Who to become（他想成为谁）** → 品牌升华

## 五、6种经典开场句式

| 类型 | 句式模板 | 示例 |
|------|---------|------|
| 🔥 **反差型** | 他/她是`[身份A]`，却`[做了B]` | "他是一名律师，却在山里种了10年地" |
| 🔢 **数字型** | `[数字]`+`[反常识事实]` | "花500万，只造了30平米的房子" |
| ❓ **悬念型** | 这个`[人]`，有一个`[秘密]` | "这个女孩，每天凌晨3点起床" |
| 🌄 **场景型** | 在`[地点]`，有`[反常识景象]` | "在上海市中心，藏着一片竹林" |
| 🎬 **动作型** | 先画面3秒，后出旁白 | 手部特写/食物特写开场 |
| 💬 **对话型** | 人物第一句话直接开场 | "我这辈子最后悔的事，就是……" |

**开头画面铁律**：80%以"大全景"或"特写"开场，绝不用中景。

## 六、单条视频生产 SOP

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  「100位普通人」单条视频 SOP
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📅 前期（2天）
  □ 选人：用四维筛选法打分（≥8颗星开拍）
  □ 前采：电话聊30-60分钟，用"五段式故事结构"逐段走
  □ 写骨架：确定开场hook + 8-10个信息点 + 结尾金句
  □ 写脚本：完整旁白 + 人物原声卡点 + 镜头清单
  □ 约时间地点

📹 拍摄（半天到一天）
  □ 空镜30分钟（拍他的生活/工作场景）
  □ 访谈60分钟（自然聊天，手机架着拍就行）
  □ 补拍20分钟（跟他走一段日常、拍几个细节）

✂️ 后期（1天）
  □ 粗剪：把故事线理出来（3分钟）
  □ 旁白：600字以内，讲8个信息点
  □ 配乐：选一首情绪匹配的纯音乐
  □ 字幕：加上人物金句的醒目字幕
  □ 封面：一张最有故事感的人物照

📊 发布
  □ 标题：用"反差型"或"数字型"句式
  □ 封面文字：一句话概括（≤12字）
  □ 发布时间：晚上8-10点
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

### 拍摄方法（三个基本动作）

1. **上下** — 垂直移动
2. **左右** — 水平移动
3. **变焦** — 推拉

### 拍摄要点

- 自然光为主，不用人工补光
- 受访者在自己的真实空间里拍摄
- 每个镜头停留2-3秒以上，不用快速剪辑
- 重视环境音（风声、水声、工具声）

### 后期配乐情绪曲线

```
[0-15秒]  开场：轻柔，建立氛围（钢琴/弦乐）
[15-45秒] 第一段：平稳叙事，音乐降到背景
[45秒-1:30] 第二段：情绪下沉，音乐渐弱至近无
[1:30-2:15] 第三段：温暖回归，催泪段
[2:15-2:45] 第四段：力量上升，重启段
[最后30秒]  第五段：走向高潮
[最后5秒]  收尾，配一个长镜头停留
```

## 七、系列内容统一格式

### 栏目名

**主标题**：《普通人的重启》
**副标题**：记录100个普通人在AI时代重新开始的故事

### 标题格式

`「人物身份」+ 「反差事实」`

示例：
- 「外卖小哥跑了3年，在车里写了20万字小说」
- 「她50岁开始学画画，现在是画廊签约画家」
- 「这个保安大叔，读了3000本书」

### 封面格式

人物正面照 + 一句金句

### 系列开头统一语

```
"第 ___ 位普通人：___（名字/代号），___（一句话身份标签）"
```

### 系列结尾统一语

```
"每个人都有自己的故事。这是第 ___ 位。
  下一期，你想听谁的故事？"
```

## 九、参考资料

### 一条方法论来源
1. [徐沪生混沌大学授课全文](https://www.sohu.com/a/217845736_754180) — 最详细的一手资料
2. [人民网/CCTV专访](http://media.people.com.cn/n1/2019/0509/c14677-31076293.html) — 拍摄方法、转型历程
3. [优酷许维深度分析](https://www.sohu.com/a/78860922_114949) — 商业模式拆解

### 徐沪生关键方法论总结
- 内容必须模块化、可复制，反对依赖灵感
- 第一条视频就定好模板，之后复制
- 选题能力是第一底层能力
- 选题会一票否决制
- 剪辑比例极致（10小时→3分钟）
- 节奏精确到每一秒
