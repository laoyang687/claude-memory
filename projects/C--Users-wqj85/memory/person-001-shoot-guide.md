# 第001号选题 · 拍摄执行清单

> 设备：手机 + 手机稳定器/三脚架 + 领夹麦
> 时间：半天（建议周末下午+傍晚）
> 原则：不追求完美，先拍出来

---

## 🎒 出门前检查

```
□ 手机充满电
□ 带充电宝
□ 手机存储空间够（至少20G）
□ 领夹麦克风充好电
□ 三脚架/稳定器
□ 纸巾（擦镜头用）
□ 两个手机（一个拍，一个备用）
```

---

## 📹 拍摄流程（按顺序）

### 第一站：聊天（60分钟）⬅️ 最重要

**地点**：他家客厅/茶室/安静的地方
**方式**：手机架在三脚架上，对着他，按录制，然后你就跟他聊

**必须聊到的6段话**（用你自己的方式问，别照着念）：

| # | 引导话题 | 你要拿到的那句话 |
|---|---------|-----------------|
| 1 | "聊聊你老家呗" | 东北农村的描述（画面感） |
| 2 | "当时为啥想创业？" | "想让乡亲们致富"这段 |
| 3 | "怎么失败的？" | 上杠杆、信用卡那段 |
| 4 | "最崩溃的是哪天？" | "100万变负债300万" 🔥 |
| 5 | "老婆怎么说？" | 她支持你的细节 |
| 6 | "你现在最想做什么？" | "帮创业者讲故事" 🔥 |

**拍摄要点**：
- 手机横着拍（16:9）
- 他占画面一半，留一半给背景
- 让他自然说，说跑题了也没关系，后期剪
- 你别说话太多，让他多说
- **每段录完看一下质量，没问题继续**

---

### 第二站：拍他的日常（30分钟）

跟着他过一遍日常，你只管拍，不用说话：

```
□ 他在电脑前学AI的画面（从背后拍 + 从侧面拍）
□ 电脑屏幕的特写（AI编程/AI作图的画面）
□ 他的手在键盘上打字的特写
□ 他翻书/看手机学习画面
□ 他泡茶/喝水的日常动作
□ 他看窗外/发呆的侧脸
```

---

### 第三站：拍他的家庭（20分钟，需征得家人同意）

```
□ 他和孩子在一起的自然画面（不用看镜头）
□ 他和老婆的日常互动
□ 全家吃饭/聊天的远景
□ 孩子的某个温暖细节（比如画/作业/玩具）
```

---

### 第四站：拍空镜（20分钟）

```
□ 他住的小区/街道的外景
□ 他每天出门上班的路
□ 他工作环境的照片（风电场照片翻拍也行）
□ 傍晚的夕阳/天空调色画面（结尾用）
□ 他一个人走路的背影
```

---

### 第五站：补拍金句（10分钟）

**这一步很重要**——单独让他对着镜头说几句话：

```
□ 让他用最自然的状态说出：
  "每一个创业者，都值得被看见。"

□ 再让他自然地说一句：
  "那天打开手机银行，从将近100万变成了负债300万。"

□ 再来一句：
  "我出生在东北的农村小山村……"
```

> **为什么要单独拍？**
> 聊天时录的可能角度不好、光线不好。金句单独拍一条，画质有保障，后期好用。

---

## ⚠️ 拍摄注意事项

### 能做的 ✅
- 多拍，别心疼存储空间（拍完能删）
- 同一个场景多拍几个角度
- 录像的时候尽量别打断他
- 他哭了/沉默了别关机，继续录（那是最真的瞬间）
- 拍完告诉他"聊得很好"

### 别做的 ❌
- 别让他对着稿子念
- 别说"你再说一遍"（说了也没关系，但尽量减少）
- 别在嘈杂的地方录访谈
- 别追求每一帧都完美

---

## 📱 手机拍摄设置

```
□ 分辨率：4K（如果手机支持）
□ 帧率：30fps
□ 格式：横屏（手机横着拿）
□ 对焦：点一下他的脸锁定
□ 曝光：往下滑一点（稍微暗一点比过曝好看）
□ 防抖：开起来
```

---

## 🎬 拍完之后

```
□ 把视频传到电脑上
□ 粗看一遍，标记出最打动你的3个片段
□ 告诉小可，我们一起写旁白+剪辑框架
```

---

## 万一拍砸了怎么办？

**没关系。**

第一条视频不是作品，是**练习**。
拍完看一遍你就知道第二条怎么拍了。
一条的第一条视频也拍了几十遍才定下来。

> **完成 > 完美。先拍出来。**
