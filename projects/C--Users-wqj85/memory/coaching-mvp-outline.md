# AI时代个人商业系统陪跑 · MVP 大纲

> 2026-07-23 创建。定位文档 [[lao-yang-ip-positioning]] 的顶端变现产品。
> 设计逻辑：老杨自己怎么从负债300万爬起来的，就帮客户怎么爬。

## 一句话产品定义

**帮一个有行动力的普通人，在3个月内，用AI搭出他自己的第一个"能变现的最小闭环"。**
- 承诺的是"跑通一次从0到收到钱"，不是"赚X万"。
- 底气：老杨自己就是从PDF卖9.9、门店设计150元这种最小闭环起步的。

## 筛选标准（=护城河）
- 收：有行动力 / 想搞副业或转型 / 有某领域经验或故事 / 能坚持3个月
- 不收：只听课不做 / 想躺赚 / 不愿暴露自己 / 抱怨甩锅型
- 筛选逻辑是 [[100-ordinary-people-sop]] 四维筛选法的延伸。

## 12周三阶段（复制三套方法论）

**第一阶段 1-4周 定位与故事**：挖故事(五段式)→提炼为什么是你→一句话定位→写自己的000号先导片
**第二阶段 5-8周 内容与私域**：选题体系(四维)→AI产出内容→搭私域承接→跑通内容→私域→信任飞轮
**第三阶段 9-12周 产品与成交**：设计最小交付物(AI做)→落地私域成交公式→第一次成交→复盘迭代

## 交付形式（控制老杨时间）
- 每周集体课×1 + 每周小班答疑×1(3-5人/班) + 每月1v1×1 + 社群助教陪伴
- 老杨周投入约3-4小时。绝不做纯1v1。

## 定价策略（套老杨自己的私域公式）
- 信任=活样本 / 痛点=AI时代重启焦虑 / 结果=3个月最小闭环 / 稀缺=首批限10人 / 低门槛=内测价
- 建议内测价 1980-2980元/3月（首批10人）→ 跑出案例后正式价 6980-9980元
- 复刻"99元低门槛→后端升高价"打法

## ⭐ 核心飞轮（三个齿轮咬合的圣杯）
栏目《普通人的重启》选品+建信任 → 筛出有行动力的人 → 付费陪跑 → 跑通闭环的客户 → 案例回流当栏目主角。
陪跑产品与 [[100-ordinary-people-sop]] [[gaokao_project]] 三齿轮自此咬合成一台自我增殖的机器。

## MVP成功标准
- ≥3人跑完全程
- ≥1人实现第一次成交（证明闭环）
- 产出2-3个可展示案例（反哺栏目）

## 待用户拍板（3件事）
1. 内测定价（建议1980-2980）
2. 交付形式（纯线上小班 / 线上+线下集训）
3. 首批客户来源（现有私域 / 等栏目流量）

拍板后下一步：写招募文案 / 设计第一周课件 / 搭招生漏斗。
