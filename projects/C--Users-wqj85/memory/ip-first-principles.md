# 个人 IP 第一性原理（校准锚）

> 2026-07-23 沉淀。
> [[lao-yang-ip-positioning]] 回答"你是谁"；本文回答更底层的"做个人IP的规律是什么"。
> **用法**：每次犹豫"这条内容该不该发、这个人设该不该立、这个产品该不该卖"，拿出来对一遍。

---

## 一、最底层的一句话

**做个人 IP 最重要的是：不是"做"出一个 IP，而是"是"那个人。**

"做"出来的是角色，"是"的才是人。角色能演一时，人才能撑一世。

## 二、为什么（IP 的本质）

个人 IP = **信任的规模化**。让一万个没见过你的人，愿意信你、为你付费。

信任靠的不是爆款，是**长期的、跨场景的一致性**：
> 你说的 = 你写的 = 你卖的 = 你做的 = 你私下的。

**所有塌房的 IP，死因都不是没流量，是不一致。**

## 三、可操作的纪律

> 找到一个你能用余生去兑现的价值主张，然后知行合一地、长期一致地活出来。

"一个真实且一致的人"是时间的朋友——时间越长，复利越深。
护城河不是某条爆款，是 **N 年没塌过**。

## 四、老杨的赢面

老杨的 IP——负债300万翻身、北大女儿、45岁学AI——**全是真的**。
不需要演，如实放大即可。最大护城河 = **真实经历的一致性**（活过，所以说得出口）。

价值主张已定（见 [[lao-yang-ip-positioning]]）：帮普通人在AI时代搭商业系统。

## 五、⚠️ 三个断裂陷阱（每次决策前自查，命中即停）

| 陷阱 | 自查问题 | 命中处理 |
|---|---|---|
| **追热点跑偏** | "这条内容和我定的价值主张有关吗？" | 无关 → 不发 |
| **立做不到的人设** | "这个人设我能持续兑现吗？我已经是了吗？" | 不是 → 不立 |
| **内容产品三张皮** | "我讲的、我卖的、我私下做的，是同一件事吗？" | 对不上 → 砍掉其中一个 |

## 六、一句话墙贴

> **做 IP 不是做一个角色，是放大一个真实的你。**
